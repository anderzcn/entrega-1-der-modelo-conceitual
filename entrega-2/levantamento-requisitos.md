## 3. Perguntas feitas e respostas obtidas


### 3.1 Cadastro de clientes

| Pergunta | Resposta |
| :---- | :---- |
| Quem pode comprar da Rafimex? | Só empresas com CNPJ regular (B2B). |
| Quem faz o cadastro do cliente? | O representante comercial, de forma manual. |
| Que dados são pedidos? | Razão social, CNPJ, inscrição estadual, endereço completo, e-mail, telefone, além do limite de crédito definido pelo financeiro. |
| Com que frequência o cadastro é revisado? | Não existe revisão periódica: só é atualizado quando o representante lembra de perguntar. |
| O que acontece quando o cadastro fica desatualizado? | Boleto vai para o contato errado e não é pago (em casos graves, o CNPJ do cliente vai para cartório), e mercadoria volta por mudança de endereço, gerando taxa de reentrega. |
| A empresa fica sabendo antes? | Não. Só descobre depois do prejuízo. |

### 3.2 Análise de crédito

| Pergunta | Resposta |
| :---- | :---- |
| Toda venda passa por análise de crédito? | Toda venda no boleto (a prazo) passa pelo financeiro, que confere o limite e o Serasa. |
| E se o cliente tiver restrição no Serasa? | Só pode comprar à vista ou no cartão. |
| E se o cliente dever para a própria Rafimex? | Nenhuma venda é liberada. |

### 3.3 Pedido, desconto e frete

| Pergunta | Resposta |
| :---- | :---- |
| Quem emite o pedido? | O representante externo ou o vendedor interno. |
| Todo pedido tem um representante? | Sim, todo pedido tem cliente e representante vinculados. |
| Qual é a alçada de desconto? | Até 4% o representante concede sozinho; acima disso, o pedido fica retido para aprovação da diretoria. |
| Como é a entrega? | Pela transportadora ou retirada na empresa. |
| O preço cobrado pode mudar depois? | Não. O preço praticado na venda vale mesmo que a tabela mude depois. |

### 3.4 Estoque e entrega programada

| Pergunta | Resposta |
| :---- | :---- |
| Dá para vender produto que ainda não chegou? | Sim, produto em importação pode ser vendido como entrega programada, desde que a data prevista de chegada apareça no orçamento. |
| Como a empresa sabe quando repor? | Quando o item atinge o ponto de pedido, é gerada uma ordem de compra ou importação. |

### 3.5 Faturamento e expedição

| Pergunta | Resposta |
| :---- | :---- |
| Quando o pedido é faturado? | Depois de aprovados o crédito e a disponibilidade, com emissão da NF-e. |
| Quem separa e despacha? | A expedição (5 pessoas). |

### 3.6 Cobrança e recebimento

| Pergunta | Resposta |
| :---- | :---- |
| Como o boleto é cobrado? | O boleto é gerado e enviado ao cliente; o pagamento dá baixa no título. |
| Qual é o prazo do boleto? | 30, 60 ,90 e 120 dias, conforme o número de parcelas.  |
| O boleto é parcelado? | Sim, a Rafimex vende parcelado no boleto.  |
| O que acontece com quem não paga? | A inadimplência bloqueia o cliente para novas vendas. |

### 3.7 Devolução e reentrega

| Pergunta | Resposta |
| :---- | :---- |
| Como a devolução é registrada? | A logística registra o retorno da mercadoria. |
| O cliente é bloqueado depois de uma devolução por endereço errado? | Hoje não, e por isso o próximo pedido pode sair para o mesmo endereço errado. |
| Quais são os motivos mais comuns de devolução? |  endereço desatualizado e avaria no transporte |
| Quanto custa uma reentrega? |50% do frete original |

### 3.8 Comissão

| Pergunta | Resposta |
| :---- | :---- |
| Qual é o percentual de comissão? | 8% para representantes externos e 3% para vendedores internos. |
| Quando a comissão é paga? | Só depois que o cliente paga o boleto. |

### 3.9 Compras, importação e contas a pagar

| Pergunta | Resposta |
| :---- | :---- |
| De quem a Rafimex compra? | De fornecedores homologados (cadastrados com CNPJ). |
| Como a importação é controlada? | A ordem de importação registra a previsão de chegada, que permite vender o produto antes de ele chegar. |
| O que acontece quando a mercadoria chega? | Entra no estoque e gera os títulos no contas a pagar, com o registro dos impostos. |

## 4. O que foi observado no local


| # | O que observamos | Onde / como | O que isso mostrou para o modelo |
| :---- | :---- | :---- | :---- |
| O1 | o cadastro do cliente não tem nenhum campo de data de confirmação | tela do sistema  | Necessidade da coluna `DT_DATA_DE_ATUALIZACAO` e da trava de 90 dias (RN09) |
| O2 | o pedido indica se o item sai do estoque ou é entrega programada | pedido impresso / tela | Coluna `DT_PREVISAO_CHEGADA` em ITEM_PEDIDO (RF07) |
| O3 |  mercadoria devolvida volta para a expedição sem bloquear o cliente |  expedição | Colunas de devolução na NOTA_FISCAL e bloqueio do cliente (RN13) |



### Diferenças entre o que foi dito e o que foi visto

Não houve divergência. O que o entrevistado descreveu foi confirmado pela observação da rotina no local: o cadastro manual feito pelo representante, a análise de crédito no boleto, a alçada de desconto, a indicação de entrega programada no pedido e o registro das devoluções sem bloqueio do cliente.

## 5. Problemas identificados

| Código | Problema | Exemplo real (sem nome de cliente) | Como o banco resolve |
| :---- | :---- | :---- | :---- |
| P1 | Cadastro desatualizado sem aviso prévio | Transportadora foi entregar e o local estava com placa de "aluga-se" | Data de atualização + aviso de quem vence em 15 dias (G02) + trava de 90 dias (RN09) |
| P2 | Boleto não recebido / inadimplência | boleto enviado a e-mail antigo, CNPJ foi a cartório | Contas a receber, taxa de inadimplência (G04), bloqueio do inadimplente (RN04) |
| P3 | Devolução e taxa de reentrega por endereço errado | 50% do valor do frete original| Registro de devoluções, custo de reentrega (G05), bloqueio até revalidar (RN13) |
